# Bundled fonts

All fonts are stored locally so the application works offline.

- `MonaspaceNeonNF-Regular.otf`: Monaspace Neon NF from GitHub Next, SIL Open Font License 1.1. Source: https://github.com/githubnext/monaspace
- `Orbitron-Variable.ttf`: Orbitron variable font from Google Fonts, SIL Open Font License 1.1. Source: https://github.com/google/fonts/tree/main/ofl/orbitron
- `ChakraPetch-Medium.ttf` and `ChakraPetch-SemiBold.ttf`: Chakra Petch from Google Fonts, SIL Open Font License 1.1. Source: https://github.com/google/fonts/tree/main/ofl/chakrapetch

The corresponding license texts are included next to the font files.
